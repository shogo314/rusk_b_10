# 構文とスコープ

[設計ノートの入口](README.md)

## 現在

トップレベルの実行文がプログラムの入口になる。文末は`;`、コメントは`//`を使う。名前付き関数と型はトップレベルに置き、定義順によらず参照できる。`include`はその位置に内容を展開し、ファイルごとの名前空間を作らない。

同じスコープでの再宣言は拒否し、内側のブロックでは外側の名前を隠せる。変数は型推論または型注釈を使う。初期値なしの宣言には型が必要で、後で最初に`:=`で初期化する。`let x = value;`は宣言とコピーによる初期化を一緒に行う別の構文である。

if文・式、ブロック式、while・for・loop、ループelse、ラベル付きbreak/continueを使える。ブロック式の末尾式は`;`なしで結果を返し、末尾式がなければUnitになる。ループelseは利用者のbreakで終了した場合には実行しない。

比較の連鎖は中間値を一度だけ評価し、最初の偽で短絡する。`??`も左辺を一度評価し、不在のときだけ右辺を評価する。match、ガード、orパターン、if let・while letは同じ型・共有の検査を使う。

タプルの分解宣言と既存変数への分解代入を扱う。`=`では更新前の値をコピーしてから左辺を処理し、`:=`では共有先を結び直す。式の評価順序と副作用を保持し、代入先を重複評価しない。

厳密な表記は[文法一覧](../docs/reference/grammar.md)、意味は[規則](../docs/reference/semantics.md)を参照する。

## 今後の方針・未決定事項

名前付き専用引数・既定値、ローカル型・名前付き関数のスコープを拡張したい。名前探索と捕捉環境の準備は[関数](functions.md)で扱う。

代入式を大きい式へ埋め込む際の括弧の必須化と、一時オブジェクトへの代入の最終制限は未決定。現在パーサーが受け付けることを、すべて最終仕様として固定する意味ではない。

`else if`、`do while`、値付きbreak、非ループへのジャンプ用ラベル、letチェーン、配列・範囲・`@`パターンは現在未対応である。採用範囲と優先順位は個別に決める。

回数だけを指定する短いループ、無名関数のプレースホルダー、要素ごとのドット演算は候補であり、採用済みの構文ではない。構文を増やす場合も、共有・評価順・制御移動を既存の意味規則に接続する。
