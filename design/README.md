# 設計方針と今後の課題

このディレクトリは、現在の言語を支える判断基準と、未実装の方針・未決定事項をまとめる。現在使える構文とAPIは[言語リファレンス](../docs/reference/index.md)と[標準ライブラリ](../docs/library/index.md)、実装状況は[対応範囲](../docs/reference/status.md)を参照する。

## 読み方

各分野を「現在」「今後の方針」「未決定・候補」に分ける。方針がある機能でも実装済みとは限らない。候補は採用を決めていない案であり、例の記号・型名だけで仕様が確定したとは扱わない。次版の実装順序や完成条件も、ここから自動的には決まらない。

| 分野 | 内容 |
|---|---|
| [設計原則](principles.md) | 競技プログラミング、書きやすさ、速度、変換先 |
| [値と共有](values.md) | オブジェクト、コピー、更新、権限、寿命、評価順 |
| [型と数値](types.md) | 基本型、広い整数・Float・ビット列、導出、再帰型 |
| [構文とスコープ](syntax.md) | 宣言、式、分岐、ループ、将来の糖衣構文 |
| [関数とジェネリクス](functions.md) | 捕捉、名前探索、静的な受け渡し、引数、定数評価 |
| [コンテナと走査](collections.md) | 共有、無効化、スライス、集計、辞書・集合 |
| [標準ライブラリ](library.md) | 命名、フック、extern、入出力と拡張 |
| [エラーと失敗](errors.md) | 異常終了と通常の不在の区別 |
| [未決定事項の一覧](review.md) | 分野をまたぐ判断と実装前の確認事項 |

概要は[将来の方針](../docs/future.md)、処理系とライブラリの分担は[アーキテクチャ](../docs/development/architecture.md)にある。

現在の実装範囲と進め方は[作業計画](../docs/development/plan.md)を参照する。

## 過去の記録

版ごとの要件は[履歴の入口](history/README.md)から参照する。以前の分野別ノートもそこに保存する。未実装時の仮記法や未決定事項を含むため、現在の仕様の根拠には使わない。実装・検証・性能の記録は[開発記録](../docs/development/history.md)にある。
