# 未決定事項の一覧

[設計ノートの入口](README.md)

現在の機能と未実装の方針を組み合わせる際に、決める必要がある問いをまとめる。採用済みの仕様や次版の実装計画ではない。

| 論点 | 現在 | 今後の判断 |
|---|---|---|
| 名前探索 | ローカル関数・型、直接の引数型からの探索、包含関係による隠蔽、ジェネリックな引数数による順位 | 名前付き・既定引数を加える場合の候補選択との接続 |
| 捕捉と再帰 | 無名関数・ローカル関数は宣言実行時のオブジェクトを共有し、再帰・相互再帰は元の環境を使用 | 循環共有と再帰型を導入する場合の環境の寿命 |
| 権限 | readonly注釈と共有経路への伝播 | 外側・要素・返却値の権限の型表記と変換 |
| 寿命 | Objと証明できた借用・値保持 | 再帰型、循環共有の可否と解放、コピー・比較の停止性 |
| 走査 | has_next/nextと変更回数の検査 | Optionを返すnextへの接続、zipの終端消費、逆向き走査 |
| 配列 | 共有要素のVec、文字への共有を持つStr | スライス、直接格納配列、使用中とみなす範囲 |
| 数値 | 検査付きIntと明示変換 | FloatのNaN・無限大・丸め、広い整数とリテラル、ビット列 |
| 引数と推論 | 位置引数、明示した引数型、限定した期待型伝播 | 名前付き専用引数、既定値、無名関数の型省略 |
| 導出とキー | 標準の構造展開、限定したキー型 | 比較・ハッシュの明示導出、独自キーと契約 |
| コンパイル時評価 | 型による具体化 | 値引数、定数式、副作用、資源上限 |

既定値の評価と捕捉環境、ローカル型の持ち出しとジェネリック探索、readonlyな要素と変更可能な外側のコンテナは、分野をまたいで設計する必要がある。

β10で採用した仕様と検証例は[ローカル関数・名前探索の仕様](local-functions.md)にある。捕捉環境の準備と持ち出しは、その仕様に従って実装・検証する。

LLVM、Unicode専用型、動的な共通関数型は、現在の基盤を整える前提ではない。性能改善は意味の一致と測定で確認する。文書例・examplesの追加時に検証漏れを作らないことも継続課題である。
