# β04の実装と検証

β04は関数の静的な受け渡し・無名関数の捕捉と、それを使う列の操作・探索・データ構造を追加しています。[合意した要件](https://github.com/shogo314/rusk_b_04/blob/main/design/beta04.md)、[文法と捕捉](../reference/closures.md)、[API](../library/algorithms.md) も参照してください。

## 処理系の構成

`src/compiler/callables.rs` は、引数型を検査し、外側の自由な変数を収集して、捕捉環境用の型と呼び出し用のC++関数を作ります。環境の各値は通常の共有オブジェクトです。呼び出し先は関数の型ごとに決まるため、`std::function` や実行時の呼び出し先検索は使いません。

呼び出し開始時には環境から捕捉値への共有をローカル名へ受け取ります。これにより中身の更新は共有し、名前の結び直しはその呼び出し内だけに作用します。コピーは構造体と同じ型別のコピー関数を使います。捕捉環境へのフィールドアクセス・直接更新はソース側では許可しません。

`src/compiler/higher_order.rs` は関数の引数・戻り型に応じて、標準の変換・集計・探索・ソートを具体化します。遅延イテレータには元の走査とコールバック、必要なら判定済みの次要素と終了状態を保持します。構造変更の検査は、変換を何段連結しても元の配列まで届くようにします。

優先度キューとセグメント木は `examples/beta04/library/` にRuskで記述しています。セグメント木は結合則・単位元、比較は厳密弱順序、境界探索は条件の単調性を利用者の契約とします。処理系がそれらの数学的性質を証明するものではありません。

## 関数付き処理の性能

2026年11月7日、WSL2 / Linux 6.6.87.2、AMD Ryzen AI 9 HX 370、GCC 15.2.0で測定しました。生成C++は `-std=c++20 -O2`、コンパイルを除きプロセスの起動・入出力を含む7回の中央値です。実装を交互に実行し、全ての回で出力一致を確認しています。

| 処理 | β04 | β04最適化無効 | Ruskで手書きした対応処理 | 手書きC++ |
|---|---:|---:|---:|---:|
| 100万要素のmap・filter・fold | 100.91 ms | 127.24 ms | 26.90 ms | 2.57 ms |
| 10万構造体のキー付き安定ソート・全件出力 | 25.93 ms | 34.89 ms | 20.93 ms | 10.99 ms |

列処理の手書き版は同じ計算を一つのループにまとめています。ソートのRusk手書き版は `(key, 元の位置)` のタプルを通常の `sort` で並べ替え、同じ安定な順序を得ます。比較しているのは処理全体で、全ての差を単独の関数呼び出しのコストとは扱いません。

この測定では列処理の連結が手書きループの約3.75倍、キー付きソートが対応処理の約1.24倍の時間です。静的な呼び出しでも、共有ポインターの受け渡し、呼び出しの戻り値の確保、各走査段階の検査、保存するキーのコピーなどの負担が残ります。一般のユーザー関数をまたぐ値の実体化の削減や、意味を保った走査の融合は今後の課題です。

## β03からの退行確認

基準はβ03最終コミット `263c87d2a03077d0e3a9bab92f42ff86a562964b` です。

| 既存の処理 | β03 | β04 |
|---|---:|---:|
| 整数入力100万個と合計 | 29.42 ms | 29.20 ms |
| 整数出力20万行 | 5.21 ms | 5.43 ms |
| 整数ループ100万回 | 14.43 ms | 13.70 ms |
| ソート・探索 | 14.01 ms | 13.79 ms |
| グリッドBFS | 28.72 ms | 28.91 ms |
| Fenwick Tree | 40.73 ms | 41.36 ms |

この環境の既存6項目では約−5〜+4%で、大きな退行は見られません。短時間・単一環境の測定なので数%の差を有意な改善・悪化とは扱いません。新しい関数付き処理の負担や、全ての問題でPyPyより速いこととは別に評価します。

## 再測定する

```bash
cargo build --release --locked
python3 tools/benchmark.py --compiler target/release/rusk \
  --baseline-compiler /path/to/beta03/target/release/rusk \
  --compare-no-opt --repeats 7 --output /tmp/rusk-beta04-benchmark.json
```

関数付きの2項目はβ03には文法・APIがないため、β03で同じソースを実行する代わりに、β04で書いた手動の対応処理と比較します。既存6項目には同じソースをβ03でも使います。

特定の項目だけなら `--case callback_fold --case callback_sort` などを指定します。[測定JSON](beta04-benchmark.json) に環境、処理系・ソース・入力のハッシュ、各回の時間、PyPyを含む全ての値を保存しています。CIでは性能の時間閾値を合否判定に使いません。
