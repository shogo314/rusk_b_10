# 作業計画

## 開始点

β10は、[β09完成版](https://github.com/shogo314/rusk_b_09/commit/30833c1cb3e82e96a32de11a0a0f71fb0b86315b)の処理系・標準ライブラリ・テスト・文書を引き継いで開始します。β09の作業内容と検証結果は[開発記録](beta09.md)に保存しています。

## 検討する範囲

関数内関数、オーバーロード、ジェネリック内の名前解決を中心とする案があります。以下は仕様を決めるための検討項目で、β10の実装範囲と完成条件はこれから確定します。

| 分野 | 決めること |
|---|---|
| 関数内関数 | 宣言のスコープ、捕捉する値、環境を準備する時点、定義前の呼び出し、再帰・相互再帰 |
| オーバーロード | 内側と外側の候補集合、名前の隠蔽、適用できる候補がない場合の扱い |
| ジェネリック内の名前解決 | 定義側と呼び出し側の探索範囲、利用者が渡す操作、具体化との関係 |

現在の規則と候補は[関数とジェネリクスの設計](https://github.com/shogo314/rusk_b_10/blob/main/design/functions.md)と[未決定事項](https://github.com/shogo314/rusk_b_10/blob/main/design/review.md)を出発点にします。

## 進め方

1. 現在の名前解決と捕捉の規則を整理し、代表的な利用例を使って仕様を決めます。
2. 採用する範囲、互換性、実装順序、完成条件を計画に反映します。
3. 実装に合わせて現行文書・フォーマッタ・API文書生成を更新し、共有・評価順序・契約と既存コードを検証します。

ほかの候補は[将来の方針](../future.md)にあります。
