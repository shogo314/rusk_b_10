# 作業計画

## β10の完了

β10は、ローカル関数・型、捕捉、名前探索・オーバーロード、静的な関数候補群の受け渡しと、関連ツールへの接続を完了しました。実装範囲・完成条件・全体検証は[β10の開発記録](beta10.md)に保存しています。現在使える機能と制限は[対応範囲](../reference/status.md)を参照してください。

## 次版の方向性

β11は「ライブラリ拡充のための道具作り」を軸に検討します。再帰型、コピー・ハッシュの操作と自動生成、返却値・要素のreadonly、コンパイル時の値引数、空のstructを検討対象とし、採用範囲・具体的な規則・実装順序・完成条件はこれから確定します。これらはβ10の実装済み機能ではありません。

ほかの候補は[将来の方針](../future.md)、設計上の論点は[未決定事項](https://github.com/shogo314/rusk_b_10/blob/main/design/review.md)を参照してください。
