# 関数の受け渡し・捕捉・遅延走査

具体的な名前付き関数と、外側の値を捕捉する無名関数を渡せます。呼び出すコードは型から静的に決まります。共有・コピー・評価順序は[基本規則](semantics.md)に従います。

## 無名関数の文法

```ebnf
lambda = "(" parameters ")" "=>" expression ;
parameters = [ identifier ":" type { "," identifier ":" type } ] ;
```

引数名と型を明示し、式を本体にします。戻り型は本体から推論します。引数なしは `() => expression` です。ブロック式を本体にでき、複数文・末尾式・明示的な`return`も使えます。引数型の省略と`_ + 1`のプレースホルダー形式は未対応です。

```rusk
fn square(x: Int) -> Int { return x * x; }
fn apply<T, F>(x: T, operation: F) -> T { return operation(x); }

let plus_one := (x: Int) => x + 1;
let squared := square;
wt plus_one(3), squared(4), apply(5, plus_one); // 4 16 6
wt ((x: Int) => x * 2)(7);                    // 14
```

`f(x)` のほか、`functions[0](x)` のような取得結果も呼べます。構造体のフィールドが関数を保持する場合は `holder.operation(x)` と呼べます。それ以外の `value.method(x)` は同じ規則で `method(value, x)` の糖衣構文です。関数を保持するローカル変数もメソッド形式の呼び出しに使えます。

通常の具体的な関数は `square` のように名前だけで渡します。オーバーロード集合や、まだ型引数が決まっていないジェネリック関数を直接渡す仕組みはありません。必要なら引数型を明示した無名関数で包み、呼び出しを一つに決めます。

```text
let integer_copy := (x: Int) => copy(x);
let copied := map([1, 2, 3], integer_copy).to_vec();
```

## 関数の型と具体化

無名関数は、その生成位置と具体化された型に応じた固有の型を持ちます。型名をソースで書く構文はありません。`let` では初期値から推論し、関数や構造体では `F` のような型引数を通して受け取ります。

```text
struct Holder<F> { operation: F; }
fn Holder<F>(operation: F) -> Holder<F> {
    return Holder::<F> { operation: operation };
}
let held := Holder((x: Int) => x + 1);
wt held.operation(10);
```

同じ位置で作成するクロージャは、捕捉値が異なっても同じ型になります。異なる無名関数は引数型と戻り型が同じでも別の型です。同じ具体的な名前付き関数への参照は同じ型を使います。

```text
let a := (x: Int) => x + 1;
let b := (x: Int) => x + 2;
a := b; // 別の無名関数の型なのでエラー
```

動的に異なる呼び出し先を選んで格納する共通の関数型や、型消去による呼び出しは導入していません。関数を引数に取る処理は、その関数の型ごとに具体化します。名前付き関数の戻り型に関数型を書く専用の表記も未対応です。

## 捕捉は作成時の共有

本体が参照する外側の変数だけを、作成時点で共有して保持します。捕捉時に中身はコピーしません。捕捉する変数は初期化済みである必要があります。

```rusk
let offset := 10;
let f := (x: Int) => x + offset;
offset = 20;
wt f(1); // 21：共有する中身の更新が見える

offset := 30;
wt f(1); // 21：外側の結び直しには追従しない
```

引数名が外側と同じなら、その引数を参照し、同名の外側変数は捕捉しません。別の無名関数も捕捉できます。必要な共有を環境が保持するため、元の名前を結び直したり、その名前のスコープが終わったりしても、捕捉したオブジェクトは生存します。文字への共有が保持する元の文字列にも、[文字列の寿命・長さ変更の規則](../library/sequences.md)が適用されます。

## 捕捉した名前の更新と結び直し

呼び出し開始時に、捕捉環境から各オブジェクトへの共有をローカル名へ受け取ります。

- `captured = value` と複合代入は共有オブジェクトを更新します。外側や他の呼び出しからも見えます。
- `captured := value` はその呼び出し内の名前だけを結び直します。外側の変数や、次の呼び出しが取得する捕捉先は変更しません。

```rusk
let n := 1;
let add := (x: Int) => (n += x);
wt add(2), add(3), n; // 3 6 6

let rebind := () => (n := n + 1);
wt rebind(), rebind(), n; // 7 7 6
```

代入を返す式は対象を共有しますが、`wt` は各項目を順に評価して出力するため、この例の最初の値は後の更新より前に出力されます。

## クロージャのコピー

`let g := f` は同じ捕捉環境を共有します。`let g = f` と `copy(f)` は環境を再帰的にコピーします。実行するコードは同じで、コピーした状態は独立します。捕捉した型に対応する `copy` が必要です。

```rusk
let count := 0;
let f := () => (count += 1);
let shared := f;
let detached = f;
wt f(), shared(), detached(), count; // 1 2 1 2
```

`f = g` は同じ型の環境の外側の同一性を保ち、捕捉した格納先をコピーで置換します。`f := g` は変数の共有先を変更します。構造体と同じく、環境コピーは元の内部共有を再現しません。環境のフィールドを直接取得する公開APIはありません。

## 遅延するmapとfilter

```rusk
let calls := 0;
let values := [1, 2, 3, 4, 5];
let it := values.filter((x: Int) => x % 2 == 1)
                .map((x: Int) => x * 10 + (calls += 1) * 0);
wt calls; // 0：まだ走査していない
for x in it {
    wt x; // 10
    break;
}
wt calls;       // 1
wt it.to_vec(); // 30 50：残りだけを集める
```

`map`・`filter` は呼び出し時に配列を作らず、走査状態と関数を保持するイテレータを返します。配列、整数範囲、これらから作った遅延イテレータを入力にできます。

`map` は要素を取得するときに一度変換し、その戻り値を共有して返します。`filter` は次に通す要素を探すまで判定し、元の要素を共有します。内部の次要素の確認で判定済みの値を保持する場合がありますが、同じ候補に判定を繰り返しません。`Unit` を返す `map` は使えません。

`to_vec` は残りを消費して配列へ共有格納します。独立した値が必要なら `.map((x: Int) => copy(x)).to_vec()` など、コピーを明示します。遅延イテレータ自体を `wt` で出力する機能はありません。

### 走査状態の共有とコピー

`let other := it` は同じ走査状態を共有し、どちらで走査しても続きが進みます。`let other = it` は走査位置と判定済みの保持値、捕捉環境をコピーします。元の配列の所有者は共有し、元の配列全体をコピーする操作ではありません。

配列から作る走査は、構造変更の検出規則を引き継ぎます。途中の追加・削除・ソート・配列全体への代入などは、次の検査で位置付きエラーになります。コールバックからの構造変更も検査します。要素の更新と格納先の結び直しは、通常の配列走査と同じ共有規則です。

## 制限と関連する規則

内側の名前付き関数、名前付き引数・既定引数、無名関数の引数型省略とプレースホルダー、動的な関数型、オーバーロード集合の受け渡し、トレイト・mixinは未対応です。[readonly / mutable](access.md)は捕捉する共有にも適用されます。構文の全体は [文法一覧](grammar.md)、各アルゴリズムのAPIは [関数を使う操作とデータ構造](../library/algorithms.md) を参照してください。

[ブロック式](blocks-labels.md)を本体に書けるため、無名関数内の宣言・複数文・明示的returnも使えます。自由変数だけを捕捉し、内側で宣言した名前は捕捉対象になりません。
