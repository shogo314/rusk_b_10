# パターン分岐・ガード・if let

match、文・式のif let、while letでパターンを使えます。これらの構文は同じパターン検査と共有の規則を使います。

## パターンの種類

| パターン | 例 | 意味 |
|---|---|---|
| ワイルドカード | `_` | どの値にも一致し、束縛しない |
| 変数 | `value` | 値を共有する変数を束縛する |
| enum | `Some(x)`、`Result::Ok(x)`、`None` | variantを調べてpayloadを分解する |
| 定数 | `0`、`-1`、`true`、`'a'`、`"end"` | 基本型の値で比較する |
| タプル | `(Some(x), true)` | 各要素を照合する |
| 構造体 | `Point { x: 0, y }` | フィールドを名前で照合する。`y`は`y: y`の省略 |
| 構造体の残り | `Point { x, .. }` | 残りのフィールドを無視する |
| or | `A(x) \| B(x)` | 最初に一致する候補を使う |
| グループ | `(Some(x) \| None)` | パターンを括弧でまとめる |
| Unit | `()` | Unitに一致する |

構造体で列挙しないフィールドがある場合は`..`が必要です。`..`は最後に一度だけ書きます。型引数は対象の型から決まり、`Boxed::<Int> { value }`のように明示することもできます。タプルは位置で、構造体はフィールド名で分解します。

パターンの型は対象の型と一致しなければなりません。定数の比較には組み込みの値比較を使い、利用者の演算フックは呼びません。`"a"`と`"\u0061"`、`0`と`-0`のように表記が異なっても同じ値として判定します。

enumの型名は省略できます。対象のenumに同名のvariantがあればvariantとして解決し、それ以外の単独の識別子は変数束縛です。`_`は常にワイルドカードです。名前を取り違えたくない場合は`Event::End`のように型名を付けます。型引数とvariantの名前が同じでも別の名前として扱います。

```rusk
struct Point<T> { x:T; y:Int; }
enum Event<T> { Data(T), Empty }
let event := Event::Data(Some((2, Point::<Int> { x:3, y:4 })));
let result := match event {
    Data(Some((n, Point { x:3, y }))) => n + y,
    Data(Some(_)) | Data(None) => -1,
    Empty => 0,
};
wt result;
```

この例の出力は`6`です。入れ子のenumの内部も同じmatchで照合できます。enumそのものの定義と更新方法は[enumとmatch](enums.md)を参照してください。

## 束縛とorパターン

束縛はコピーせず、対象やpayloadを共有します。名前はそのarmのガードと本体でだけ使えます。同じ一つのパターンの中で同名を複数回束縛することはできません。

orの各候補は、同じ名前を同じ型で束縛しなければなりません。`A(x) | B(x)`は両方の`x`の型が同じ場合に使えます。`Some(x) | None`では束縛する名前が揃わないためエラーです。値を使わないなら`Some(_) | None`とします。

```rusk
let pair := (Some(1), Some(2));
let selected := match pair {
    (Some(x), _) | (_, Some(x)) => x,
    _ => 0,
};
selected = 9;
wt pair[0]?!, pair[1]?!;
```

最初の候補が選ばれるので、出力は`9 2`です。

## ガード

パターンの後ろに`if`で追加条件を書きます。条件の真偽変換は通常のifと同じです。

```rusk
let value := Some(3);
wt match value {
    Some(x) if x > 0 => x * 2,
    Some(x) => x,
    None => 0,
};
```

対象は一度だけ評価します。パターンが一致しなければ、そのarmのガードは評価しません。一致したarmのガードが偽なら次のarmへ進みます。orの複数の候補に一致しても、最初の候補の束縛でガードを一度だけ評価します。偽の場合に同じarmの別の候補を試し直すことはありません。

ガードで束縛変数を`:=`により結び直した場合、一致したarmの本体にもその結び直しを引き継ぎます。ガードが偽なら、他のarmはそれぞれの確定済みの共有先を使います。

### ガード中の更新

共有による更新があっても網羅性と取り出しを安定させるため、各armのパターン判定結果と、束縛する共有先はガード実行前に確定します。ガードから対象のvariantやフィールドの共有先を変更しても、以降のarmは確定済みの結果と共有先を使います。確保済みの共有値の中身への更新は見えます。

```rusk
let value := Some(1);
wt match value {
    Some(x) if { value = None; x = 7; false } => 100,
    Some(x) => x,
    None => 0,
};
wt value.is_none();
```

出力は`7`、`Yes`です。二番目のarmは開始時点のSomeに対応する共有先を使うため、variant変更後に無効なpayloadを参照しません。判定は取り直しません。定数パターンについても、ガード後の値で比較し直すことはありません。

確定した共有先はmatchの処理中に保持されます。そのため、ガードで元のenumを更新しても、後続armが使う文字参照などが生存し、その所有者の文字列のサイズ変更を制限する場合があります。共有先を深くコピーして固定する規則ではありません。

## 網羅性と到達不能

match文・match式の両方で、すべての値を処理する必要があります。enum・Bool・タプル・構造体とその入れ子について、各要素の組み合わせも検査します。ガード付きarmは網羅性の根拠には使いません。

例えば`Some(Some(_))`と`None`だけなら、`Some(None)`が不足していると表示します。IntやStrを定数だけで分岐する場合は、残りを処理する変数パターンや`_`が必要です。CharはASCIIの値域で検査します。

前のガードなしのパターンによって完全に覆われたarm、重複するor候補もエラーです。ガードの式が常に真・偽かまでは証明しません。複雑すぎるパターンには解析・展開量の上限があります。

## if letの文と式

`if let pattern = expression`で、一つのパターンに一致したときだけ処理します。`=`は構文の区切りで、コピーではありません。

```rusk
let value := Some([1]);
if let Some(row) = value {
    row[0] = 5;
}
let answer := if let Some(row) = value {
    row[0] + 1
} else {
    0
};
wt answer;
```

出力は`6`です。文ではelseを省略できます。式ではelseが必要で、処理を続ける分岐の結果型を一致させます。return・break・continueで抜ける分岐は結果型を制約しません。一致側の束縛はelseやif letの外では使えません。パターンに一致するかどうかを条件として使うため、パターン自体が網羅的である必要はありません。

## while let

```rusk
let count := 0;
outer: while let Some(n) = if count < 3 { Some(count += 1) } else { None } {
    if n == 2 { continue outer; }
    wt n;
} else {
    wt "done";
}
```

出力は`1`、`3`、`done`です。各反復で対象を一度評価し、不一致で自然終了します。束縛はその反復の本体でだけ使えます。elseは自然終了時に実行し、そのwhileへのbreakでは実行しません。ラベルの範囲と外側へのbreak/continueは通常のwhileと同じです。

対象の一時値と照合で保持した共有は、その反復の終了・脱出時に解放します。本体から結果を外へ共有した場合は、その共有が残ります。if letでも対象と照合の一時値はif letの処理中に保持します。

## armの本体

ブロックのほか、式を直接書けます。直接の式は末尾にカンマが必要で、if式・if let式・match式も使えます。ブロック本体の後ろのカンマは省略できます。結果型、文として捨てる場合、ブロック式の末尾で値にする場合の規則は既存のmatchと同じです。

```rusk
let value := Some(4);
wt match value {
    Some(x) => if let Some(y) = Some(x) { y } else { 0 },
    None => match false { false => -1, true => 0, },
};
```

## 未対応のもの

再帰型、配列・スライスパターン、範囲パターン、`@`束縛、letチェーン、通常のlet宣言のパターン一般化は未対応です。[readonly / mutable](access.md)の制限は、パターンで取り出した共有にも引き継ぎます。if letとwhile letにはmatchのガード構文を直接付けません。一致側のブロックで通常のifを使います。
