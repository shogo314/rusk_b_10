# 分岐式・Option・比較の連鎖

条件分岐の結果を共有する式、不在を表す `Option<T>`、短絡する比較の連鎖を使えます。

## if式

```text
let a := [1];
let b := [2];
let chosen := if true { a } else { b };
chosen[0] = 7;  // a[0]も7
let n := 10 + (if false { 1 } else { 2 });
```

条件を一度評価して真偽値に変換し、選んだ分岐だけ評価します。値を返して継続する分岐の型は同じで、結果は選んだ値への共有です。脱出する分岐は結果の型から除外します。独立させる場合は `let chosen = if ...;` とコピーします。

`else` は必須です。各分岐には[ブロック式](blocks-labels.md)を書きます。文を並べ、末尾のセミコロンなしの式を結果にします。末尾の式がなければUnitです。`let`や`return`、外側のループへのbreak/continueも使えます。`else if`の専用構文はありません。式の最上位に置くか、算術などの一部に置くときは括弧で囲みます。単独の文頭の `if` はif文として解析されます。式文として使う場合は `(if flag { a } else { b });` とします。

未初期化変数は、両分岐で確実に初期化した場合だけ後から読めます。

Optionは[汎用enum](enums.md)で定義され、`Option::Some`・`Option::None` とmatchでも扱えます。以下の短い構築記法と専用APIも使えます。

## Optionの構築と取得

```text
let present := Some([1, 2]);
let absent: Option<Vec<Int>> := None;
let explicit := None::<Int>();
let empty := Option::<Int>();  // Noneと同じ
let value := present?!;
value[0] = 9;                 // presentの要素にも反映
wt absent.is_none(), present.is_some();
```

`Some(value)` は値を共有して格納します。`None` は型注釈や引数の文脈で型が決まる場合に使えます。文脈がない場合は `None::<T>()` と書きます。`Some::<Vec<Int>>([])` のように要素型を指定できます。`Option` の条件変換は存在すれば真、不在なら偽です。

| 操作 | 結果 |
|---|---|
| `o.is_some()` / `o.is_none()` | 存在 / 不在を表す `Bool` |
| `o.value()` / `o?!` | 中身を共有して取得。不在なら位置付き実行時エラー |
| `o ?? fallback` | 存在すれば共有取得、不在時だけ `fallback` を評価 |
| `copy(o)` / `let other = o;` | 中身を再帰的にコピー |
| `o = other;` | 外側の同一性を保ち、コピーした中身へ置換 |
| `o := other;` | 変数を別のOptionへ結び直す |

`o = None;` の前に取得した中身への共有は生存します。`o` を共有していた別の変数には、不在への変更が見えます。`Option` 全体の比較・出力は提供しません。存在を調べ、必要な中身を取り出します。

## ??と?!

```text
let d := Dict::<Str, Int>();
wt d.get("missing") ?? 0;
let value := Some(42) ?? (1 / 0); // 右辺は評価されない
wt value;
```

`??` は左辺を一度だけ評価し、`__coalesce_test__(左辺)->Bool`で存在を判定します。存在する側は`__coalesce_value__(左辺)`を共有取得し、もう一方でだけ右辺を評価します。標準では`Option<T>`がこれらの操作を定義し、右辺は`T`でなければなりません。利用者の型にも通常の関数として同じ操作を定義できます。コンパイラー内部ではif式と同じ条件分岐処理を使います。右結合で、`a ?? b ?? c` は `a ?? (b ?? c)` です。入れ子の型はこの構造に合う必要があります。

`??` は範囲演算より弱く、代入より強く結び付きます。`?!` は添字・呼び出しと同じ後置演算なので `o?![0]` と書けます。`?!`は通常の`value(左辺)`を呼びます。標準Optionの不在のエラー位置は`?!`の位置です。一般の `Never` 型や早期returnを表す演算子は導入していません。

## 比較の連鎖

```text
in x, n: Int;
wt 0 <= x < n;
wt 1 < 2 <= 2 != 3 == 3;
```

`== != < <= > >=` を混在できます。各隣接項を比較し、偽になった時点で残りを評価しません。各項は左から一度だけ評価します。各比較の結果は `Bool` が必要です。

`a() < b() < c()` では `a()`、`b()` の順に評価し、最初の比較が真の場合だけ `c()` を評価します。`b()` の結果はコピーせず保持し、両方の比較に使います。そのため `c()` がそのオブジェクトを更新すると、二つ目の比較は更新後の値を見ます。独立したスナップショットが必要なら明示的にコピーしてください。

比較はビット演算より強く結び付きます。`(mask & bit) != 0` の括弧は引き続き必要です。
