# 関数

## 定義・呼び出し・戻り値

```rusk
fn square(x: Int) -> Int { return x * x; }
wt square(5);
```

出力は`25`です。定義はトップレベルに置き、引数型を明示します。名前付き関数の戻り型を省略すると`Unit`です。値を返す関数では`-> 型`と`return value;`を書きます。名前付き関数の本体に末尾式を書くだけでは、戻り値を返したことになりません。

関数は定義より前から呼べ、再帰・相互再帰にも対応します。同名関数は引数型で選びます。暗黙の数値変換はなく、戻り型だけの違いによる通常のオーバーロードはできません。

## 引数と戻り値は共有

```rusk
fn update(x: Int) { x = 9; }
fn first(a: Vec<Int>) -> Int { return a[0]; }
let n := 1;
update(n);
let a := [2, 3];
first(a) = 8;
wt n, a;
```

出力は`9 8 3`です。引数も戻り値もオブジェクトを共有します。引数の`:=`は関数内の名前だけを結び直します。独立した値が必要なら呼び出し側・関数側で`copy`を明示します。呼び出し後も、返したローカル値や取得した要素への共有は有効です。

## 型引数とメソッド形式

```rusk
fn duplicate<T>(x: T) -> T { return copy(x); }
wt duplicate(7), duplicate::<Str>("abc");
```

出力は`7 abc`です。型引数は実引数と期待する返却型から推論するか、`::<...>`で指定します。明示型引数と期待型は一致する必要があります。型引数付き関数は具体的な型に応じて検査・生成されるため、その本体で使う操作を実際の型が提供する必要があります。トレイト境界を書く構文はありません。

`value.f(args)`は通常`f(value, args)`の糖衣構文です。この形式を**UFCS（Uniform Function Call Syntax）**と呼びます。一般的な概念は[Wikipedia日本語版](https://ja.wikipedia.org/wiki/Uniform_Function_Call_Syntax)、Ruskでの評価順は[メソッド形式](index.md#method-syntax)を参照してください。

ただし関数を保持する構造体フィールドなどの呼び出しは、その関数値を呼びます。明示的な型引数を使う場合は`f::<T>(value, args)`と書きます。[型引数と構造体](records.md)も参照してください。

## 無名関数と捕捉

```rusk
let offset := 10;
let add := (x: Int) => {
    let answer := x + offset;
    answer
};
offset = 20;
wt add(2);
offset := 100;
wt add(2);
```

出力は両方とも`22`です。外側の値はクロージャ作成時に共有して捕捉します。共有している中身の変更は見えますが、外側の変数を別の値へ結び直しても捕捉先は変わりません。

無名関数は引数型を明示し、結果型を推論します。式一つの本体、ブロック本体、ブロック内の明示的`return`を使えます。`let g := f;`は捕捉環境を共有し、`let g = f;`は捕捉した値を再帰的にコピーします。

## 関数値の型と制限

各無名関数は生成位置と具体化された型に応じた固有の型を持ちます。同じ引数型・戻り型でも、別の位置の無名関数は別の型です。共通の`Fn(...)`型を書く構文や型消去はありません。型引数`F`で受け取る関数・構造体と組み合わせます。

具体的な名前付き関数は`let f := square;`のように渡せます。オーバーロード集合や型引数が未確定の関数は、`(x: Int) => copy(x)`のように包んで呼び出しを決めます。名前付き関数はトップレベルの実行文で宣言した変数を捕捉しません。
