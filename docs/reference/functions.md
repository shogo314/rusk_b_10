# 関数

## 定義・呼び出し・戻り値

```rusk
fn square(x: Int) -> Int { return x * x; }
wt square(5);
```

出力は`25`です。定義はトップレベルやブロック内に置き、引数型を明示します。名前付き関数の戻り型を省略すると`Unit`です。値を返す関数では`-> 型`と`return value;`を書きます。名前付き関数の本体に末尾式を書くだけでは、戻り値を返したことになりません。

捕捉が不要な関数は定義より前から呼べます。捕捉が必要な関数は環境の準備後に呼べ、再帰・相互再帰にも対応します。同名関数は引数型で選びます。暗黙の数値変換はなく、戻り型だけの違いによる通常のオーバーロードはできません。

同じ引数型の定義も、別の候補として保持します。定義が複数あるだけではエラーにせず、呼び出しで一意に選べなければコンパイルエラーにします。戻り型や引数の契約注釈の違いでは候補を選びません。

ブロック内の名前付き関数は、そのブロック内から参照できます。捕捉が不要なら定義前から呼べ、捕捉が必要なら環境の準備後に呼べます。再帰・相互再帰にも対応します。内側に同名関数があれば、外側の同名候補群全体を隠します。内側の候補に引数型が適合しなくても、外側へ戻りません。ジェネリック本体の通常名は定義位置から解決し、具体化した呼び出し元の同名定義で置き換えません。

通常の探索に加え、直接の実引数型の宣言スコープからも、最も近い同名候補群を集めます。候補スコープのうち別の候補スコープの外側にあるものを除き、包含関係のないスコープの候補は両方残します。同じ宣言を複数の引数型から見つけても一候補です。`Vec<T>`の型引数`T`や、フィールド型・タプル要素の型までは探索しません。演算子フックも同じ規則を使います。[ローカル型](records.md#local-types)に関連操作の例があります。

名前付きローカル関数は、外側の変数を[無名関数](closures.md)と同じ共有規則で捕捉できます。宣言の実行時に捕捉先を保持し、元の束縛の結び直しには追従しません。再帰・相互再帰も同じ捕捉先を使います。捕捉が必要な関数は、必要な環境の準備前に呼び出したり、関数値として取得したりするとコンパイルエラーになります。

トップレベルの実行文は名前付き関数の宣言より内側の実行スコープとして扱い、変数名でグローバル関数名を隠せます。グローバルな名前付き関数は、トップレベルの実行変数を捕捉しません。

## 引数と戻り値は共有

```rusk
fn update(x: Int) { x = 9; }
fn first(a: Vec<Int>) -> Int { return a[0]; }
let n := 1;
update(n);
let a := [2, 3];
first(a) = 8;
wt n, a;
```

出力は`9 8 3`です。引数も戻り値もオブジェクトを共有します。引数の`:=`は関数内の名前だけを結び直します。独立した値が必要なら呼び出し側・関数側で`copy`を明示します。呼び出し後も、返したローカル値や取得した要素への共有は有効です。

## 型引数とメソッド形式

```rusk
fn duplicate<T>(x: T) -> T { return copy(x); }
wt duplicate(7), duplicate::<Str>("abc");
```

出力は`7 abc`です。型引数は実引数と期待する返却型から推論するか、`::<...>`で指定します。明示型引数と期待型は一致する必要があります。型引数付き関数は具体的な型に応じて検査・生成されるため、その本体で使う操作を実際の型が提供する必要があります。トレイト境界を書く構文はありません。

複数の候補が引数に適合する場合、宣言の引数型に型パラメータを含む引数の数が少ないものを選びます。`(T, Int)` は1個、`(T, T)` と `(T, U)` は2個です。`Vec<T>` や `(T, U)` のような複合型も、一つの引数位置なら1個と数えます。明示型引数を指定しても数は変わりません。同じ最少数の候補が複数あれば曖昧です。`f<T>(T)` と `f<T>(Vec<T>)` の間には順位を付けません。

通常の具体関数は0個として扱います。型パラメータが戻り型だけにあるジェネリック関数も0個なので、両方に適合する呼び出しは曖昧になります。選ばれた関数の本体が型検査に失敗しても、別の候補へ戻ることはありません。

ジェネリックなローカル関数も外側の変数を捕捉します。具体化によって捕捉する名前が決まっても、保持する共有先と初期化状態は宣言時点のものです。同じ宣言の複数の具体化は、その宣言で保持した共有先を使います。未使用のジェネリック本体は具体化しません。

```rusk
{
    let count := 0;
    fn next<T>(unused: T) -> Int { count += 1; return count; }
    wt next(0), next("a"), count; // 1 2 2
}
```

`value.f(args)`は通常`f(value, args)`の糖衣構文です。この形式を**UFCS（Uniform Function Call Syntax）**と呼びます。一般的な概念は[Wikipedia日本語版](https://ja.wikipedia.org/wiki/Uniform_Function_Call_Syntax)、Ruskでの評価順は[メソッド形式](index.md#method-syntax)を参照してください。

ただし関数を保持する構造体フィールドなどの呼び出しは、その関数値を呼びます。明示的な型引数を使う場合は`f::<T>(value, args)`と書きます。[型引数と構造体](records.md)も参照してください。

## 無名関数と捕捉

```rusk
let offset := 10;
let add := (x: Int) => {
    let answer := x + offset;
    answer
};
offset = 20;
wt add(2);
offset := 100;
wt add(2);
```

出力は両方とも`22`です。外側の値はクロージャ作成時に共有して捕捉します。共有している中身の変更は見えますが、外側の変数を別の値へ結び直しても捕捉先は変わりません。

無名関数は引数型を明示し、結果型を推論します。式一つの本体、ブロック本体、ブロック内の明示的`return`を使えます。`let g := f;`は捕捉環境を共有し、`let g = f;`は捕捉した値を再帰的にコピーします。

## 関数値の型と制限

ローカル関数の値は、必要な捕捉先への共有を保持するため、宣言したブロックの外でも呼べます。共有とコピーも無名関数と同じです。

```rusk
let next := {
    let count := 0;
    fn increment() -> Int { count += 1; return count; }
    increment
};
let shared := next;
let detached = next;
wt next(), shared(), detached(); // 1 2 1
```

捕捉した名前を関数内で `:=` により結び直しても、その呼び出しのローカル名だけが変わります。次の呼び出しと再帰先は元の環境から名前を受け取ります。

各無名関数は生成位置と具体化された型に応じた固有の型を持ちます。同じ引数型・戻り型でも、別の位置の無名関数は別の型です。共通の`Fn(...)`型を書く構文や型消去はありません。型引数`F`で受け取る関数・構造体と組み合わせます。

名前付き関数は`let f := square;`のように渡せます。オーバーロード集合やジェネリック関数も名前のまま渡し、呼び出す引数型から静的に選択・具体化します。同じ宣言群と環境の型を使う参照は同じ型になり、実行時の捕捉値の違いでは型を分けません。

参照にも`identity::<Int>`のように型引数を指定できます。不明な型や型引数の個数違いは、関数値を呼び出さなくても参照時に診断します。

```rusk
fn apply<T, F>(value: T, operation: F) -> T { return operation(value); }
let operation := copy;
wt apply(3, operation), apply("abc", operation); // 3 abc
fn duplicate<T>(value: T) -> T { return value + value; }
wt [1, 2].map(duplicate).to_vec(); // 2 4
```

参照した場所の候補と元の関数名を保持します。別名や高階関数を経由しても、呼び出す場所の同名定義で置き換えません。呼び出し時には、直接の実引数型から見つけた候補も加え、通常の隠蔽・順位・曖昧さの規則で選びます。関数値が保持する字句的な捕捉先は共有・コピーの対象になり、追加の関連操作が必要とする環境は呼び出す場所から渡します。型の値だけで環境を運ぶことはありません。

トップレベルの名前付き関数はトップレベルの実行文で宣言した変数を捕捉しません。
