# 対応機能と制限

このページは現在の処理系で使える範囲を示します。使える型と型ごとの操作は[型の一覧](types.md)、記号と評価規則は[演算子](operators.md)を参照してください。未実装の方針と検討案は[将来の方針](../future.md)に分けて記載しています。

## 実装済み

| 分類 | 対応内容 |
|---|---|
| 基本値 | 符号付き64ビット`Int`・128ビット`Int128`、64ビット`Float`、`Bool`、ASCIIの`Char`・`Str`、`Unit` |
| 変数 | 型推論・型注釈、共有・コピー、更新と結び直し、スコープ、[readonly/mutable](access.md)、初期化前の使用検査、[fixed/rebindable](bindings.md) |
| 演算 | 検査付き整数演算、IEEE 754の四則演算、累乗、ビット演算・シフト、全順序`<=>`、比較の連鎖、短絡論理、最小・最大と更新 |
| 制御 | if文・式、ブロック式、for・while・loop、ループelse、ラベル付きbreak・continue |
| 型 | 配列、タプル、構造体、型引数、payload付きenum、Option |
| パターン | 入れ子、リテラル、構造体、or、ガード、match文・式、if let・while let |
| 関数 | [noescape/escape](escape.md)、トップレベルの名前付き関数、再帰・相互再帰、オーバーロード、型引数、関数値、捕捉する無名関数 |
| ライブラリ | 辞書・集合、遅延走査・enumerate・zip・逆向き走査、集計・探索・ソート、各種データ構造 |
| extern | 外部ジェネリック型・関数、型・操作・コールバックの参照、作成者が保証する引数契約、共有/Unit ABI、相対C++資源と依存の宣言 |
| ツール | C++生成、IR出力、位置付き診断、フォーマッタ、ライブラリ検索・API文書生成、ローカルとCIの検証 |

## 現在使えないもの

- 任意精度整数、固定長・可変長ビット列、Unicodeの文字列操作。
- ビット複合代入、`++`・`--`、`else if`、`do while`。
- スライス、配列・範囲・`@`パターン、if letチェーン。
- 値付きbreak、ブロックに付けるジャンプ用ラベル。
- 内側の名前付き関数、名前付き・既定引数、無名関数の引数型省略。
- 型消去した共通の関数型、トレイト、mixin。
- 自身を再帰的に含む型定義、例外処理、LLVMバックエンド。

## 書くときに気を付ける境界

`let a := [];`は要素型を決められません。`let a: Vec<Int> := [];`のように型の手がかりを与えます。配列に格納できる型や、比較・ソート・入出力ができる型にはそれぞれ条件があり、すべての型で全操作が使えるわけではありません。

タプルは2要素以上です。Unitの値は`{}`などで作り、値の式として`()`は使いません。一方、パターンの`()`はUnitに一致します。

文字列の文字を共有している間は、元の文字列の長さを変更できません。配列走査中の構造変更も検査します。詳細は[配列と文字列](../library/sequences.md)を参照してください。

コンパイル時にすべての実行時エラーを予防するわけではありません。添字、ゼロ除算、オーバーフロー、不正入力、Optionの不正な取り出しなどは[位置付きの実行時エラー](errors.md)になります。

## externと解析の境界

外部ジェネリック型・関数は通常の候補解決と具体化を使います。標準操作も通常の宣言で定義し、特定のライブラリ名を理由に本体を生成しません。コンパイラに残す構文・構造・ABI・解析の共通処理は[役割分担](../development/architecture.md)を参照してください。

契約のないexternの効果は未知です。型付き参照や標準由来という情報だけでreadonly/noescapeを安全とは判断しません。解析には追跡量の上限もあり、安全なプログラムでも証明できず拒否する場合があります。[externの信頼条件](../development/extern.md)と各注釈の制限を参照してください。
