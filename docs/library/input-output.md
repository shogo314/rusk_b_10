# 入出力

## 基本値を読む

```rusk
in n: Int, word: Str, marker: Char, flag: Bool;
wt n, word, marker, flag;
```

入力が`42 hello A true`なら、出力は`42 hello A Yes`です。

| 型 | 読み込み規則 |
|---|---|
| `Int` | 空白区切りの符号付き十進整数。64ビットの範囲を検査 |
| `Int128` | 空白区切りの符号付き十進整数。128ビットの範囲を検査 |
| `Float` | 空白区切りの十進・指数表記、`nan`、`inf`、`+inf`、`-inf` |
| `Str` | 空白区切りのASCII文字列 |
| `Char` | 先頭の空白を飛ばし、ASCIIの1文字を読む |
| `Bool` | `Yes` / `No`、`true` / `false`、`1` / `0` |

`in`は変数を新しく宣言します。既存変数へ読む代入文ではありません。同じスコープで同名変数を再宣言するとエラーです。型別の入力処理`__read__`を呼びます。

## 長さを指定して配列を読む

```rusk
in n: Int, a(n): Vec<Int>;
wt a;
```

入力が`3 8 5 2`なら、出力は`8 5 2`です。項目は左から処理されるため、同じ`in`文で先に読んだ`n`を使えます。長さは入力データの個数であり、配列リテラルではありません。

| 宣言の例 | 読む値 |
|---|---|
| `in a(n): Vec<Int>;` | 整数をn個 |
| `in grid(h, w): Vec<Vec<Int>>;` | h行w列の整数。行優先 |
| `in pair: (Int, Str);` | 整数、文字列を順に一つずつ |
| `in pairs(n): Vec<(Int, Str)>;` | 整数・文字列の組をn個 |

タプルのための括弧やカンマを入力へ書く必要はありません。標準の配列入力では各次元の長さが必要で、`in a: Vec<Int>;`とは書けません。負の長さや格納形式の上限を超える長さは実行時エラーです。入力APIの型ごとの条件は[辞書・集合と入力API](collections.md)も参照してください。

## EOFまで読む

```rusk
let total := 0;
while let Some(x) = try_read::<Int>() {
    total += x;
}
wt total;
```

入力が`3 5 -2`とEOFなら、出力は`6`です。`try_read::<T>()`は引数なしの`__read__() -> T`で読み、読み始める前の正常なEOFでは`None`、読めた場合は`Some(value)`を返します。基本型`Int`・`Float`・`Bool`・`Char`・`Str`に加えて、`try_read::<(Int,Str)>()`のようなTupleや、入力関数を定義した構造体等にも使えます。`T`を明示すると型が確実に決まります。

不正なトークン、整数の範囲外、非ASCII入力は`None`ではなくエラーです。読み始めた後のEOFもエラーです。例えばTupleの途中で入力が切れても、`None`にはしません。通常の`in`も値が必要なので、EOFはエラーです。配列を読む場合は、長さの指定も行う引数なしの入力関数を用意します。

## 行を読む

`read_line()`は現在位置から改行までを読みます。LFと末尾のCRを取り除き、行内の空白は保持します。最後の行が改行なしで終わっていても、その行の内容を返します。読み始めた時点でEOFならエラーです。

```rusk
in n: Int;
let rest := read_line();
let next := read_line();
wt n;
wt rest;
wt next;
```

入力：

```text
2 hello world
next line
```

出力：

```text
2
 hello world
next line
```

トークン入力は後続の区切りを消費しません。そのため`rest`の先頭には空白が残ります。数値の直後が改行なら、最初の`read_line()`は空文字列を返します。

## 出力の形式

`wt expression, ...;`は各項目を左から順に評価・出力します。項目間に空白を一つ、末尾に改行を出します。`wt;`は改行のみです。後の項目の評価が始まる前に、先の項目は出力されます。

`Int`と`Int128`は符号付き十進整数として出力します。Int128リテラルの接尾辞`i128`はソースコードで使う表記です。

```rusk
wt true, false;
wt [1, 2], (3, "abc");
let empty: Vec<Int> := [];
wt empty;
```

出力の最初の2行は`Yes No`、`1 2 3 abc`で、3行目は空行です。配列・タプルは要素を空白区切りで展開し、括弧やカンマは出しません。多次元配列も自動で行ごとに改行するわけではないため、行を分けるなら`for row in grid { wt row; }`と書きます。

### Floatの入出力 { #float-io }

`wt x`と`Str(x)`は、Floatとして読み戻すと同じ有限値になる短い十進表記を使います。指数表記を選ぶ場合もあります。負のゼロは`-0`、特殊値は`nan`、`inf`、`-inf`です。`in x: Float;`と`Float(text)`はこれらの表記を受け付けます。不正な文字列や、有限値の範囲を超える十進入力、非ゼロからゼロに丸まる入力は実行時エラーです。

`format_fixed(x, digits)`は小数点以下を0〜1000桁で指定し、固定小数点表記のStrを返します。例えば`format_fixed(2.5, 3)`は`"2.500"`です。無限大・NaNには通常出力と同じ表記を使います。

文字列は引用符なし、文字はその1文字を出します。ユーザー定義型をすべて自動で表示できるわけではありません。出力に対応する型・操作が必要です。

配列・タプルは各要素の型に対応する通常の`__write__(value) -> Unit`を呼びます。構造体等に出力関数を定義すると、その型を要素とするタプルやタプルの配列にも使えます。要素は左から順に出力し、出力関数による変更にも通常の共有規則が適用されます。タプル全体に対する利用者の出力関数が通常の候補として選ばれる場合は、その定義を使います。
