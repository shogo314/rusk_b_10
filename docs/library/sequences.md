# 配列と文字列

## Vecの構築と添字

`Vec<T>`は同じ型の要素を格納する可変長配列です。基本型、タプル、構造体、enum、入れ子の配列などを格納できます。型によって使用可能な操作は異なります。

| 書き方 | 共有とコピー |
|---|---|
| `[a, b]` | 各要素を共有して格納 |
| `[x; n]` | xを一度評価し、各要素へ独立したコピーを格納 |
| `let a: Vec<Int> := [];` | 要素型を指定して空配列を作る |
| `a[i]` | 要素を共有して取得 |
| `a[i] = x` | 取得した要素の中身を更新 |
| `a[i] := x` | その位置の格納先をxへ変更 |

添字は0始まりです。`-1`は末尾、`-len(a)`は先頭です。範囲外は実行時エラーで、空配列に有効な添字はありません。

```rusk
let row := [0; 3];
let grid := [row; 2];
grid[0][1] = 7;
wt grid[0];
wt grid[1];
```

出力は`0 7 0`と`0 0 0`です。繰り返し初期化は内側もコピーするため、2行は独立しています。

## 基本API

通常の関数形式とメソッド形式の両方を使えます。例えば`len(a)`と`a.len()`は同じ操作です。

| 操作 | 戻り値・振る舞い | 計算量の目安 |
|---|---|---|
| `len(a)` | 要素数のInt | O(1) |
| `push_back(a, x)` | xを共有して追加 | 償却O(1) |
| `pop_back(a)` | 末尾を削除し、その要素を共有して返す。空ならエラー | O(1) |
| `copy(a)` | 要素を再帰的にコピーした独立配列 | コピーする内容全体に比例 |
| `a = b` | 外側の同一性を保ち、bの各要素をコピーして置換 | コピーする内容全体に比例 |
| `a + b` | 外側が新しい配列。要素は共有 | O(N+M) |
| `a += b` | aの外側を保ち、bの要素を共有して連結 | 追加要素数と再確保に依存 |
| `reverse(a)` | 要素の並びを反転 | O(N) |
| `contains(a, x)` | 値が一致する要素の有無 | O(N)回の比較 |
| `find(a, x)` | 最初の位置をOption<Int>で返す | O(N)回の比較 |
| `sum(a)` / `sum(a, initial)` | 走査順の合計。省略時の初期値は要素型の`T()` | O(N)回の加算。[集計](algorithms.md#aggregation) |

要素を取得した後に配列が拡張・削除されても、取得済みの要素への共有はそのオブジェクトを保持します。配列のイテレータの有効性とは別の規則です。

## ソートと二分探索

| 操作 | 振る舞い |
|---|---|
| `sort(a)` | 要素の`<=>`による安定ソート。要素の共有は保持 |
| `sorted(a)` | 外側だけ新しく作り、要素の`<=>`で安定ソート。要素は元と共有 |
| `bisect_left(a, x)` | x以上となる最初の挿入位置 |
| `bisect_right(a, x)` | xより大きくなる最初の挿入位置 |

ソートはO(N log N)回程度の比較、二分探索はO(log N)回の比較です。二分探索には要素の`<`に従って昇順に整列した配列を渡します。構造体などで従来の`__lt__`だけを定義していた場合、既定のソートには`__cmp__`を追加するか、比較関数を渡します。 [全順序](../reference/operators.md#total-order)・[比較関数付きソート](algorithms.md#sorting)

```rusk
let a := [3, 1, 2];
let ordered := a.sorted();
ordered[0] = 9;
wt a;
wt ordered;
```

出力は`3 9 2`と`9 2 3`です。`sorted`は深いコピーではありません。独立させたい場合は`let ordered = a; ordered.sort();`のようにコピーしてから整列します。

## 配列を走査するとき

`for x in a`は要素を共有します。要素の中身の更新と`a[i] := value`は可能です。一方、追加・削除・反転・ソート・連結・配列全体への`=`などの構造変更は走査を無効にし、次の検査で位置付きエラーになります。遅延するmap・filterも元の配列の変更検査を引き継ぎます。

## StrとChar

`Str`はASCII文字列、`Char`はASCIIの1文字です。文字列の添字も負数に対応します。

| 操作 | 振る舞い |
|---|---|
| `len(s)` | 文字数。O(1) |
| `s[i]` | 元の文字列内の文字を共有 |
| `s[i] = c` | 元の文字を書き換える |
| `s + t` | 独立した文字列を作る |
| `s += t` | 元の文字列へ追記 |
| `push_back(s, c)` | 1文字を追記 |
| `contains(s, t)` / `contains(s, c)` | 部分文字列・文字の有無 |
| `Char + Int` / `Char - Int` | ASCII範囲内で文字を移動 |
| `Char - Char` | ASCIIコードの差をIntで返す |

`s[i] := c`による文字の格納先の結び直しはできません。

```rusk
let s := "cat";
let letter := s[0];
letter = 'b';
wt s;
letter := 'x';
s.push_back('!');
wt s;
```

出力は`bat`と`bat!`です。`letter := 'x'`で文字への共有を手放してから長さを変更しています。

文字への共有が残っている間、`push_back`、空でない文字列の`+=`、長さが変わる`=`は実行時エラーです。同じ長さへの`=`は可能で、取得済みの文字にも更新が見えます。文字への共有は元の文字列の寿命も保持します。

## 型変換

| 呼び出し | 主な対応 |
|---|---|
| `Int(x)` | Intのコピー、Boolの0/1、CharのASCIIコード、Strの整数解析 |
| `Bool(x)` | Int・Bool・Char・Str・Vecの真偽変換 |
| `Char(x)` | Charのコピー、Int・BoolのASCIIコード、長さ1のStr |
| `Str(x)` | Int・Bool・Char・Strの表示、Vec<Char>の連結 |
| `Int()` / `Bool()` / `Char()` / `Str()` | 0、false、NUL文字、空文字列 |

不正な整数形式・範囲外のコード・非ASCII値などは実行時エラーです。型の暗黙変換は行いません。

条件式の真偽変換と、`Bool(x)`という関数呼び出しの対応範囲は別です。Dict・Set・Optionは条件式に使えますが、これらに対する標準の`Bool(x)`は提供していません。UnitからInt・Bool・Char・Strへの標準変換もありません。

配列・タプルの比較は、通常の要素型の比較を使います。`<=>`は全要素の`<=>`を左から使い、最初の異なる要素で決まります。配列で共通する先頭部分が等しければ短い方が先です。
